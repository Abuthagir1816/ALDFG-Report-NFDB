📋 Field Protocol & GGGI Guidelines

Data collection standards aligned with ECSA Principles, GGGI Best Practice Framework, and FAO Voluntary Guidelines.

📸 Photo Protocol

  • Minimum 3 photos per gear sighting (overview, close-up, scale reference)
  • Include a 1m scale bar or common object in frame
  • Ensure GPS/EXIF metadata is enabled on device
  • Photograph any entangled/trapped organisms separately
  • Record drone footage at minimum 4K / 30fps
  • SCUBA: note dive computer depth/time in same frame if possible

📍 GPS Accuracy Standards

  • Record to minimum 6 decimal places (±1 m accuracy)
  • Use WGS84 datum (default on all smartphones)
  • For long stretches, record start and end coordinates
  • Drone surveys: record centroid of gear patch
  • Multiple gear aggregations: record each separately

⚠️ Safety Guidelines

  • Never attempt SCUBA retrieval solo — minimum 2-diver rule
  • Do not cut or disturb gear with entangled live animals
  • Contact local fisheries dept. / coast guard before removal
  • Wear cut-resistant gloves when handling monofilament
  • Shore-based surveys: follow coastal safety protocols

🔗 GGGI Data Pathway

  • Data exported from this portal is GGGI Best Practice compliant
  • Upload CSV to: gggi.org/data-portal (free registration)
  • FAO-VG flag columns auto-populated in export
  • For major removals: submit to GGGI Gear Retrieval Database
  • Cite as: ALDFG Watch India / ICAR-CIFE, [Year]

🧬 eDNA Integration

  • Collect 1L water sample within 2m of ALDFG sighting
  • Filter through 0.45μm membrane, freeze immediately
  • Link eDNA sample ID to ALDFG report Reference ID
  • Use paired field blank and negative control per transect

🚁 Drone Survey Protocol

  • Fly at 30–50m AGL for gear detection transects
  • Minimum overlap: 75% for photogrammetry
  • Ground control points: minimum 5 per survey area
  • Report flight log ID alongside ALDFG reference
  • Comply with DGCA NPNT requirements for coastal airspace

🔗 Connect to Google Sheets (Live Sync)

Follow these steps to wire this portal to your Google Sheet so every submission auto-populates a new row in real time.

📋 Step-by-Step Setup Guide
1

Create Your Google Sheet

Go to sheets.google.com → Create a new sheet named ALDFG_NFDB_Master. Create two tabs: Reports and Species_Log. Copy the Sheet ID from the URL — it's the long string between /d/ and /edit.

2

Open Google Apps Script

Go to script.google.com → New Project → Name it ALDFG Data Receiver. Replace all code with this:

function doPost(e) { try { var ss = SpreadsheetApp.openById('PASTE_YOUR_SHEET_ID_HERE'); var data = JSON.parse(e.postData.contents); if (data.type === 'report') { var sheet = ss.getSheetByName('Reports'); sheet.appendRow([ data.ref, data.date, data.time, data.reporter, data.email, data.org, data.reporterType, data.district, data.state, data.location, data.lat, data.lon, data.habitat, data.depthBand, data.exactDepth, data.gearType, data.material, data.size, data.weight, data.condition, data.source, data.severity, data.retrieval, data.notes, data.mediaCount, new Date().toISOString(), 'Yes', 'Yes' ]); } if (data.type === 'species') { var spSheet = ss.getSheetByName('Species_Log'); var entries = data.speciesEntries || []; entries.forEach(function(sp) { spSheet.appendRow([ data.ref, data.date, data.observer, data.observerType, data.lat, data.lon, data.depthStart, data.depthEnd, data.depthAvg, data.visibility, data.tempC, sp.species, sp.group, sp.condition, sp.count, data.notableSpecies, new Date().toISOString() ]); }); } return ContentService .createTextOutput(JSON.stringify({status:'success'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({status:'error',message:err.toString()})) .setMimeType(ContentService.MimeType.JSON); } }

Replace PASTE_YOUR_SHEET_ID_HERE with your actual Sheet ID.

3

Deploy as Web App

Click Deploy → New Deployment → Type: Web App → Execute as: Me → Who has access: Anyone → Click Deploy → Copy the Web App URL.

4

Paste URL into This File

Open this index.html file in a text editor. Find line at the top:

const SHEETS_WEBAPP_URL = "PASTE_YOUR_WEB_APP_URL_HERE";

Replace PASTE_YOUR_WEB_APP_URL_HERE with the URL you copied. Save the file. If hosted on GitHub Pages, commit the change — submissions now auto-sync to your sheet.

5

Share the Sheet with Your Team

In Google Sheets → Share → Add your co-investigators and advisory committee emails. Set to Viewer or Editor as needed. They can monitor incoming data live from any device.

6

Deploy Website via GitHub Pages (Free Shareable URL)

1. Go to github.com → New repository → name it aldfg-portal → Public → Create
2. Upload this index.html file (already wired with your Sheet URL)
3. Go to repository Settings → Pages → Source: main branch → Save
4. Your live URL will be: https://[your-username].github.io/aldfg-portal
5. This URL is citable in your thesis, NFDB report, GGGI submission, and FAO data portal.
